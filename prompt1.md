## 6. Модуль shamir.py

Реализуй стандартную пороговую схему Шамира.

Используй соглашения:

- n — число участников;
- t — порог приватности;
- k = t + 1 — минимальное число долей для восстановления.

Для секрета s генерируется многочлен:

f(x) = s + a₁x + ... + aₜxᵗ.

Доли:

share_i = (x_i, f(x_i)),

где x_i — попарно различные ненулевые элементы поля.

Реализуй:

- генерацию долей;
- восстановление секрета;
- восстановление из произвольного допустимого подмножества;
- пользовательские точки вычисления;
- проверку параметров.

Не используй точку x = 0 как точку участника.

По умолчанию коэффициенты a₁,...,aₜ равномерно независимы, включая возможность нулевых старших коэффициентов. Это обеспечивает стандартную t-приватность; фактическая степень случайного многочлена может быть меньше t.

### Тесты

Проверь:

1. Восстановление из любых k долей на малых параметрах.
2. Восстановление для различных секретов.
3. Восстановление нулевого секрета.
4. Восстановление при t = 0.
5. Отклонение некорректных долей и повторяющихся точек.
6. Отклонение набора меньше k долей стандартным API восстановления.
7. Статистическую проверку приватности на небольших примерах.
8. Точную проверку приватности посредством полного перебора коэффициентов для очень маленьких полей и параметров.

Важно: не утверждай, что случайные статистические тесты доказывают приватность. Доказательство следует из свойств схемы Шамира; тесты лишь подтверждают реализацию на выбранных случаях.

## 8. Модуль code_square.py

Реализуй покомпонентное произведение кодовых слов:

c * c' = (c₁c'₁, ..., cₙc'ₙ).

Для линейного кода C определи квадрат:

C^{*2} = span{c * c' : c,c' ∈ C}.

Обязательно реализуй:

- покомпонентное умножение;
- построение набора попарных произведений строк порождающей матрицы;
- приведение матрицы к ступенчатому виду над GF(p);
- вычисление ранга матрицы над GF(p);
- построение базиса квадратного кода;
- вычисление размерности C^{*2};
- вычисление минимального расстояния квадратного кода перебором на маленьких параметрах.

Для обычных кодов Рида–Соломона с одинаковыми точками вычисления должно выполняться:

RS(n,k)^{*2} = RS(n,min(n,2k−1)).

В частности:

dim(C^{*2}) = min(n,2k−1).

Это теоретическое утверждение необходимо подтвердить вычислением базиса и ранга, а не просто вернуть формулу.

### Тесты

Проверь:

1. Размерность квадрата для нескольких RS-кодов.
2. Совпадение вычисленного пространства с ожидаемым RS-кодом.
3. Корректность ранга матрицы.
4. Минимальное расстояние квадратного кода для небольших параметров.
5. Пограничный случай 2k−1 ≥ n.
6. Произведения всех базисных кодовых слов.
7. Линейную замкнутость полученного квадратного кода.

## 9. Модуль multiplication.py

Реализуй операции умножения секретов посредством схемы Шамира.

Для двух секретов a и b создаются два независимых многочлена f и g степени не выше t:

f(0) = a,

g(0) = b.

Каждый участник получает f(x_i) и g(x_i).

Затем локально вычисляет:

h_i = f(x_i)g(x_i).

Поскольку:

h(x) = f(x)g(x),

имеем:

deg(h) ≤ 2t,

h(0) = ab.

Следовательно, произведение можно восстановить из 2t+1 различных значений при наличии достаточного количества участников.

Реализуй:

- покомпонентное умножение долей;
- восстановление произведения секретов;
- проверку условий мультипликативности;
- проверку условий сильной мультипликативности;
- получение вектора коэффициентов линейного восстановления произведения.

Для стандартной схемы Шамира с n участниками и t-приватностью:

- мультипликативность при n ≥ 2t+1;
- сильная мультипликативность относительно всех множеств размера не более t при n ≥ 3t+1.

Это условия для используемой модели локального умножения с линейной реконструкцией.

Важно:

- Произведение долей не является автоматически новой схемой Шамира с исходным порогом.
- Не называй обычную интерполяцию произведения полноценным MPC-протоколом умножения.
- Для реального распределённого протокола могли бы потребоваться дополнительные шаги, например понижение степени и повторное разделение секрета. Они не входят в данный этап.
- Восстановление произведения должно происходить из долей, без доступа к исходным секретам со стороны функции восстановления.

### Тесты

Проверь:

1. Произведение для случайных секретов.
2. Произведение при a = 0 или b = 0.
3. Произведение для всех пар секретов в небольшом поле при небольших параметрах, если вычислительно допустимо.
4. Восстановление из разных подмножеств размера 2t+1.
5. Сильную мультипликативность для всех допустимых удаляемых множеств на небольших параметрах.
6. Отрицательные случаи, когда число доступных долей недостаточно.
7. Правильность коэффициентов линейного восстановления.
8. Отсутствие обращения к исходным секретам при восстановлении произведения.

Особенно важно различать:

- алгоритм восстановления, который требует установленное минимальное число долей;
- математическую невозможность универсального восстановления для всех допустимых входов при меньшем числе долей.

Для отрицательных тестов не ограничивайся проверкой выброшенного исключения. Добавь математический контрпример или проверку отсутствия подходящего линейного функционала восстановления.
